# `@rack-mcp/hardware-catalog`

Precision-measured YAML hardware blueprints and `port_groups` matrix expander for **RackArchitect MCP**.

- **20 Included Blueprints:**
  - `catalog/10inch/` — 10-inch mini-rack switches, patch panels, brush panels, PDUs, and 1U UPS
  - `catalog/19inch/` — 19-inch enterprise gateways, PoE switches, and 2U UPS
  - `catalog/carriers/` — Parametric 3D-printed 1U modular carriers (`slots[]` + `printable_metadata`)
  - `catalog/sub-modules/` — Lenovo ThinkCentre M920q Tiny, Ubiquiti UCG-Max, Raspberry Pi 5 PoE HAT, and Keystone Cat6a couplers
- **Validation Command:** `pnpm validate:catalog`
